# LazyColumn-IME

## 概要
LazyColumnがIMEに追従しない挙動を確認したため、  
Jetpack Composeで検証用アプリを作成。

複数の方式を実機で比較し、  
ログを取得しながら挙動を検証した。

実装の詳細やログはQiita記事を参照。

## 実行環境
Android端末（実機検証：Xperia 5 Ⅱ / Android 12）
